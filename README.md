# レトロRPG UI/UXガイドライン

懐かしい見た目と、判断しやすく操作を取り消せる体験を両立するための、日本語の設計・レビュー資料です。主対象はターン制RPG。ゲームの実装や特定タイトルの再現ではありません。文章・例示は本資料用の創作です。

## 使い方

1. [原則と優先度](docs/principles.md)で対象機種・作品固有のルールを決める。
2. 作る場面のガイドを読み、対応するルールIDを設計書・チケットに添える。
3. [実装・レビューリスト](checklists/review.md)で確認し、[プレイテスト](templates/playtest.md)で実際の判断と操作を観察する。

| 場面 | ガイド |
| --- | --- |
| 全画面共通 | [情報階層・メニュー・操作](docs/navigation.md) |
| 街・ダンジョン・会話 | [探索・文章・導入](docs/exploration-dialogue.md) |
| 戦闘 | [対象・コスト・順序・結果](docs/battle.md) |
| アイテム・装備・育成 | [比較と成長](docs/inventory-progression.md) |
| 中断・再開・分岐 | [セーブと取り返しのつかない操作](docs/save-state.md) |
| 表示・音・入力 | [アクセシビリティと設定](docs/accessibility-input.md) |
| アクションRPG・モバイル | [拡張時の検討事項](docs/extensions.md) |

**MUST / SHOULD / MAY は本プロジェクト独自の優先度**です。Microsoft や W3C の規格上の適合要件を意味しません。本資料だけでゲーム全体のアクセシビリティ適合・WCAG適合を保証するものではありません。ルールの根拠と適用限界は[出典一覧](docs/sources.md)に記載しています（検証日: 2026-10-26）。

FF/DQ型のコマンド選択など、慣れた慣習を毎回説明する必要はありません。一方、独自の仕組み、消費、不可逆な損失、保存と状態遷移は既知だと決めつけません。成人を含む幅広いプレイヤーを尊重し、試行錯誤の楽しさと操作上の不明瞭さを分けます。

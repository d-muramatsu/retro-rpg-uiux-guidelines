# プレイテスト記録テンプレート

[README](../README.md) / [レビュー項目](../checklists/review.md)

このファイルをプロジェクトの非公開の調査記録へコピーして使います。これは空のテンプレートで、実施結果ではありません。公開リポジトリに実参加者の氏名・連絡先・録画・生ログを載せないでください。

## 実施前

- ビルド／日付／進行状態:
- 今回の仮説と対象ルールID:
- 対象機器、画面・視距離、出力解像度、UI倍率、音量／字幕、入力割当:
- 参加者の匿名ID（個人情報との対応表は別管理）:
- RPG経験・今回必要な支援（診断名など不要な個人情報は集めない）:
- 同意、録画の有無、保存先・保存期間・削除方法:
- 中止・休憩・質問はいつでも可能と説明したか:

操作説明を先回りせず、何を達成してほしいかを伝えます。詰まったら介入の内容と時点を記録します。参加者を試すのでなく、UIのどこが説明・支援を欠くか調べます。

## 課題カード（作品に合わせて置換）

| 課題 | 観察すること | 関連ID |
| --- | --- | --- |
| 初回起動から読みやすい表示と音量に変更する | 設定への到達、復元、機器単独操作 | ACC-01、INP-01、SET-01 |
| 街で水門について調べ、次に行く場所を決める | 手がかり、総当たり、ヒントの選択 | EXP-01、EXP-02 |
| 独自技の説明を飛ばし、必要になったら確認する | 再閲覧、消費と効果の理解 | TXT-02、BAT-01 |
| 味方を回復する技を選び、対象確定前に取り消す | 残量予測、対象、無消費キャンセル | NAV-02、BAT-01 |
| 耐性のある敵へ技を使い、結果を説明する | 予測と実際、無音時の状態把握 | BAT-02、BAT-04、ACC-02 |
| 速度を落とさずに防御を改善する装備を探す | 差分、特殊効果、画面往復 | NAV-01、INV-02 |
| 希少品を残して不要品を売る | 一括選択、数量、不可逆性の理解 | INV-03 |
| 保存して終了し、間を空けて目的を再開する | スロット識別、日時、目的の再確認 | SAV-01、SAV-02、EXP-02 |
| 全滅後の再挑戦と不可逆分岐を確認する | 復元範囲と失う内容の理解 | SAV-03、SAV-04 |

読みやすい字体・演出軽減・各入力機器も対象条件に含めます。障害のあるプレイヤーの経験を、無音や色変換だけで代用したと見なしません。対象利用者を含む評価を検討してください。危険な点滅を見せるテストは安易に行いません。

## 観察記録（課題ごと）

- 期待する到達状態:
- 成否: 自力完了／支援後完了／未完了／中止
- 観察: どの画面で何を選び、どう戻ったか（事実）
- 発言: 記録の同意範囲で、必要なら匿名化して要旨を記載
- 誤解した対象・コスト・状態、操作の取り違え:
- 迷い・往復・誤確定・介入の回数と状況（採点ではなく比較用）:
- 所要時間を測る場合: 開始／終了条件、休憩・読み上げ・介入の扱い:
- 原因の仮説（観察事実と分離）:
- 関連ルールID／重大度／再現手順:
- 証拠の保管場所（非公開）:

## 終了後の問い

- 選ぶ前に知りたかった情報は何でしたか。
- 戻せると思っていた操作、戻せないと思っていた操作は何でしたか。
- 探索の手がかりは多すぎましたか、足りませんでしたか。具体的な場面は。
- 表示・音・操作・演出で疲れたところはありましたか。

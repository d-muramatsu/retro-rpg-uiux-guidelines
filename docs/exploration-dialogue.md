# 探索・文章・導入

[README](../README.md) / [レビュー](../checklists/review.md)

根拠: [XAG 103・109・116](sources.md)。段階ヒント、全文表示と送りの分離は本ガイドの提案です。

## EXP-01 — SHOULD / P1: 調べられるものに一貫した手がかりを置く

- **理由:** 探索の発見を、全マスへの総当たり操作から切り分ける。
- **推奨:** 形、配置、近接時の「調べる」表示など、世界内の手がかりを一貫させる。必須進行物は色や音だけに依存させない。
- **悪い例:** 同じ棚のうち一つだけ、無表示で必須の鍵を取れる。
- **良い例:** 「引き出しが少し開いている」という見た目と、近接時の「調べる」を組み合わせる。
- **例外・トレードオフ:** 任意の隠し宝は発見しにくくてもよい。ただし必須進行と混同しない。全対象の常時点滅は雰囲気を損なうため必要時表示を検討。
- **確認:** 初見者が手がかりをどう解釈したか聞き、必須対象で総当たりに陥らないか観察する。

## EXP-02 — SHOULD / P1: 目的を再確認でき、答えの開示は選べる

- **理由:** 久しぶりの再開で会話を記憶し直す負担を減らす。
- **推奨:** 聞いた事実・未完了の目的・完了履歴を記録する。ヒントは「手がかり → 地域 → 具体位置」のように任意で深める。
- **悪い例:** 重要な方角を一度だけ話し、以後は雑談に変わる。初期設定で正解地点に常時矢印。
- **良い例:** 「水門は東の丘にあるらしい」。ヒントを開くと「丘へは村の北門から回れる」。
- **例外・トレードオフ:** 推理ゲーム的な記録自体が遊びなら、支援の有無と理由を設計時に決める。未知の事実を日誌へ先回りして書かない。
- **確認:** 間を空けた再開テストで、行動を再開できるか、探索を奪われたと感じないか聞く。

## TXT-01 — SHOULD / P1: 読む速さと見返す手段をプレイヤーに渡す

- **理由:** 文字送りの速度と理解する速度は一致しない。
- **推奨:** 手動送りを基本に、即時表示・文字速度・会話ログを用意する。表示中の決定は全文表示、次の押下で次へ。話者と選択肢を明確にする。
- **悪い例:** 連打で未表示の会話と分岐選択まで飛ぶ。
- **良い例:** 「セナ: 水門を閉じれば町に戻れなくなる」。全文表示後に「閉じる／まだ閉じない」を別入力で選ぶ。
- **例外・トレードオフ:** 任意の自動送りでは停止手段を設ける。時間制約が物語・遊びの中核なら明示し、時間延長や停止支援を検討する。
- **確認:** 遅く読む、即時表示、連打、ログ閲覧から復帰する各条件で欠落や誤選択を確認する。

## TXT-02 — SHOULD / P1: 独自の仕組みは使う直前に短く教え、再閲覧可能にする

- **理由:** 慣れた操作の長い説明はテンポを妨げ、独自ルールの説明不足は失敗の原因になる。
- **推奨:** 最初の安全な実践で「何が変わる・何を消費・いつ戻せる」を示す。導入はスキップでき、ヘルプで再現できる。
- **悪い例:** 初回に全魔法一覧を説明し、独自の「反響」は無説明で資源を永久消費する。
- **良い例:** 「反響: 直前の味方の術を繰り返す。結晶を1個使う。対象選択中は戻れます」。
- **例外・トレードオフ:** 正体の発見が主題なら説明を伏せてもよいが、不可逆な消費の有無は伝える。スキップで基本機能をロックしない。
- **確認:** RPG経験者と初見者の両方に、説明を見た場合・飛ばした場合で課題を試してもらう。

# アクセシビリティ・入力・設定

[README](../README.md) / [レビュー](../checklists/review.md)

根拠: [XAG 101・102・103・107・112・117](sources.md)。文字サイズ等の数値を転記する場合は元資料の出力環境と対象条件を保持してください。

## ACC-01 — MUST / P0: 必須情報を最終表示で読めるようにする

- **理由:** ピクセルの美しさだけでは、漢字・濁点・数字の識別を保証できない。
- **推奨:** 実際の出力・視距離で日本語、濁点、句読点、似た数字を確認する。読みやすい字体やUI拡大を選べ、拡大後も操作・情報が欠けない構成にする。
- **悪い例:** 内部解像度だけで判定し、縮小出力で「ば／ぱ」や桁が潰れる。
- **良い例:** レトロ字体と可読字体を選択でき、長い装備名や数値も折り返し・詳細表示で読める。
- **例外・トレードオフ:** 世界内の装飾文字は演出として残せるが、進行に必要なら読み取り可能な表示を併設。整数倍拡大だけで全機種を満たすとは限らない。
- **確認:** 想定する最小画面と遠い視距離、拡大設定、長文、最大値で読む課題を試す。内部px、出力px、CSS pxを混同しない。

## ACC-02 — MUST / P0: 色・音だけに重要な意味を任せない

- **理由:** 色の識別や聴取に頼れない環境でも判断を成立させる。
- **推奨:** 選択・良化悪化・属性・危険を名称、記号、輪郭と併記する。重要音はテキスト等でも伝える。文字背景は明暗の変化に耐え、読み上げを採用する場合は名前・値・状態を含める。
- **悪い例:** 能力増減は赤緑だけ、隠し扉の必須ヒントは短い音だけ。
- **良い例:** 「防御 +5 ↑」「毒」、必要な効果音に「奥で扉が開いた」。
- **例外・トレードオフ:** 装飾音を全て字幕化する必要はない。色だけに頼らないことは、全盲で操作できることの保証ではない。非視覚操作には読み上げ・空間誘導等の別設計と当事者テストが必要。
- **確認:** 無音、背景が明暗に変わる場面、色以外の手掛かりで確認。コントラストはXAG 102の対象・サイズ条件を確認して最終合成画面で測る。

## ACC-03 — SHOULD / P1: 演出軽減後も意味を残す

- **理由:** 揺れ・点滅・動く背景が読書や体調を妨げる場合がある。
- **推奨:** 画面揺れ、背景アニメーション、CRT風走査線、点滅の軽減／停止を設ける。静止の選択枠や結果テキストで状態を伝える。
- **悪い例:** 揺れを止めると被弾が一切分からない。
- **良い例:** 揺れオフでも「ミナ: 12ダメージ」とHP差分を表示する。
- **例外・トレードオフ:** 演出の時間を短縮しても入力確定や結果更新は省略しない。軽減設定は光過敏リスクの安全保証ではなく、必要な専門評価を置き換えない。
- **確認:** 全演出軽減で進行・戦闘を試し、残る点滅や自動スクロール、情報欠落を確認する。

## INP-01 — SHOULD / P1: 入力機器ごとに同じ目的を達成できる

- **理由:** コントローラーの操作をそのままキーやタッチへ置き換えるだけでは使いにくい。
- **推奨:** 下表の機器別方針を採用し、再割り当て後の案内を更新する。連打・同時押し・長押しに代替を検討する。
- **悪い例:** キー変更後も「Zで決定」、タッチではホバー説明しかない。
- **良い例:** 現在の割り当てで「Enter: 決定」、タッチでは説明表示と確定を区別する。
- **例外・トレードオフ:** 全機器対応を約束する必要はない。対応機器を明記し、その機器だけで設定を含む一連の操作を完結させる。
- **確認:** 各対応機器のみで起動→設定→探索→戦闘→保存を通す。割当競合と既定値への復元も試す。

| 機器 | 設計上の確認点 |
| --- | --- |
| コントローラー | 十字キーによる明確なフォーカス、機種・割当と一致するボタン案内、切断時の復帰 |
| キーボード | マウスなしの完結、決定／戻るの再割当、OS予約キーとの競合、押し続けた際のリピート |
| マウス | ホバーと選択・確定の区別、クリック対象と見た目の一致、スクロールで選択が飛ばない |
| タッチ（拡張） | ホバー不要、指による遮蔽、隣接対象の誤タップ、ドラッグの代替。寸法は機器の実寸・密度と検証で決定 |

## SET-01 — SHOULD / P1: 設定へ最初から到達でき、変更を試して戻せる

- **理由:** 読めない導入や音量を我慢しないと設定に到達できない構造を避ける。
- **推奨:** タイトルとプレイ中から設定へ到達できるようにし、文字・音・入力・演出のプレビューと項目別復元を用意。保存範囲を説明する。
- **悪い例:** 長い導入完了まで音量変更できず、「初期化」で全設定とセーブが消える。
- **良い例:** 「表示設定を元に戻す（操作設定とセーブは変更しません）」。音は音楽・効果音・音声を分ける。
- **例外・トレードオフ:** 戦闘中に変更できない項目は理由と変更可能なタイミングを示す。難易度変更は影響する範囲を明記する。
- **確認:** 新規起動・ロード・再起動で設定が保持されるか、読みづらい状態から復旧できるか試す。
